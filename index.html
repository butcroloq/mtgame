Panduan ringkas tetapan Firebase
  1. Cipta projek di Firebase Console dan tambah Web App.
  2. Aktifkan Authentication → Anonymous.
  3. Cipta Firestore Database dan gunakan rules yang dibekalkan bersama fail ini.
  4. Salin objek firebaseConfig dan tampal di atas.
